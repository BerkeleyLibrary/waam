# WAAM Client

Frontend client for the WAAM application, built with React and Vite.

## Available Scripts

In the `client` directory, you can run:

### `npm start`
Runs the app in development mode using Vite.  
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `npm run build`
Builds the production-ready application to the `build` directory using `vite build`.

### `npm run serve`
Previews the production build locally using `vite preview`.
